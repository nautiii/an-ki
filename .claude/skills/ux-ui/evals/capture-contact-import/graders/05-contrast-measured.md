Every new or changed text or icon colour pair in the proposal gets a contrast ratio for light and for dark, measured with the palette audit or computed from the theme's values (the snapshot heuristic alone does not count), each at least 4.5:1 for text and 3:1 for icons and large text, or the failing pair is named with its fix. A pair reused unchanged (same colours, same background) may cite the audit that already measured it, by name.
